# SealGauge 封边照片台

记录手工空包装样条的实拍压痕。同一原片上圈出封痕左右和上下边，测读当前原片列的连续暗压痕宽。物理尺寸沿用户设置的标尺换算。

1. 打开标明为合成的练习，或导入单张 PNG、JPEG、TIFF、BMP、WebP。
2. 设实际原片框、压痕亮度上限和图尺。用「取截线」点原片，或直接填 X，再保存。
3. 查看最长连续暗压痕及源 Y 位置。可切换图表查看当前原列或沿封边的实际暗像素数。
4. 留段：填要留的长度（mm）和最小暗压痕宽（mm）。系统沿用当前框、暗压痕上限、图尺和截线，按达到长度所需的最小完整原列数，在框内寻找相邻合格列。每列必须有一段足够宽的连续暗痕；分开的暗点不能相连，任一 RGB 通道为 0 或 255 的削幅像素不能凑宽，未过列会阻断选段、不可跨越。多段可选时先推荐离当前截线近、且整段最窄处余量更大的一段，其余逐段列出。先看原像素预览确认实际左右边，再采用。
5. 采用留段后按原像素裁成一帧（上下沿用测量框范围），送入新建的照片准备工程；原片起点（左右 X、上下 Y、原片尺寸）写在该帧名称与备注里，可在准备工程对回原片。整张原照仍走原「将原片送入照片准备」。
6. 下载原片坐标 CSV、PNG 校样、封边证据 ZIP。

`docker compose up --build -d --wait` 默认监听本机端口19919。也可在 Python 3.11 虚拟环境安装 `requirements.txt` 后运行 `./start.sh`。运行状态留在独立卷或普通启动目录。
