# SealGauge 封边照片台

记录手工空包装样条的实拍压痕。同一原片上圈出封痕左右和上下边，测读当前原片列的连续暗压痕宽。物理尺寸沿用户设置的标尺换算。

1. 打开标明为合成的练习，或导入单张 PNG、JPEG、TIFF、BMP、WebP。
2. 设实际原片框、压痕亮度上限和图尺。用「取截线」点原片，或直接填 X，再保存。
3. 查看最长连续暗压痕及源 Y 位置。可切换图表查看当前原列或沿封边的实际暗像素数。
4. 下载原片坐标 CSV、PNG 校样、封边证据 ZIP，或把原图交给照片准备。

`docker compose up --build -d --wait` 默认监听本机端口19919。也可在 Python 3.11 虚拟环境安装 `requirements.txt` 后运行 `./start.sh`。运行状态留在独立卷或普通启动目录。
